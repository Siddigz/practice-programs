# Practice programs

Small programs I wrote while learning to code, mostly in my first year of Computer Science at
Carleton. Each folder used to be its own repository. They're collected here with their original
commit history and dates.

For my larger projects, see my [GitHub profile](https://github.com/Siddigz).

| Folder | Language | What it does |
| --- | --- | --- |
| [simple-chess](simple-chess) | Java | Chess in Java, with a class for every piece |
| [simple-soduku](simple-soduku) | Python | A playable Sudoku game in Pygame: place numbers, win screen, restart |
| [compund-interest-calculator](compund-interest-calculator) | Python | Compound interest from principal, rate and time |
| [fruit-counter](fruit-counter) | Python | Counts how many of each fruit are in a list |
| [paragraph-intials](paragraph-intials) | Python | Groups a paragraph's words by their first letter |
| [list-to-dict](list-to-dict) | Python | Groups a list of pairs into a dictionary |
| [bubblesorting](bubblesorting) | Python | Bubble sort in both directions, with negative and non-negative numbers sorted separately |
| [divison-errors](divison-errors) | Python | Safe division that catches divide-by-zero and non-numeric input |
| [recursive-sum-notation](recursive-sum-notation) | Python | Sums of even numbers, written both recursively and with a loop |
| [recipe-processing](recipe-processing) | Python | Loads recipes from a CSV file and finds each one's secret ingredient |
| [matrix-multiplication](matrix-multiplication) | Python | Builds two matrices from user input and multiplies them |
| [adjacent-vertices](adjacent-vertices) | Python | Lists a graph's edges from its adjacency matrix |
| [customer-listing](customer-listing) | Python | Creates customer records and prints them |
| [battleship](battleship) | Python | Battleship against the computer on a random board |
| [menu-summary](menu-summary) | Python | Splits a menu list into items, prices and quantities, and totals it |
| [euclid-algorithm](euclid-algorithm) | Python | Greatest common divisor with Euclid's algorithm |
| [random-num-guesser](random-num-guesser) | Python | Guess the secret number from 1 to 100 |
| [find-divisors](find-divisors) | Python | Every divisor of a number |
| [narcissistic-numbers](narcissistic-numbers) | Python | Finds narcissistic (Armstrong) numbers in a range |
| [christmas-tree](christmas-tree) | Python | Prints a text Christmas tree of a chosen size |
| [Customer-Records](Customer-Records) | Python | Customer records, a later version of customer-listing |
| [text-counting](text-counting) | Python | Counts the words and sentences in a paragraph and capitalizes each sentence |
| [list-replacement](list-replacement) | Python | Replaces every matching element in a list |
